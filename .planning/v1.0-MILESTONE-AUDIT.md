## Gaps Detail

### GAP-01: 6 Unverified Phases (Phases 10–15)

Phases 10–15 have no `VERIFICATION.md`. These phases cover packaging, pause/resume, auto-save, title editing, copy button, and waveform layout — all executed but never formally verified.

**Impact:** Cannot confirm success criteria pass for these phases via verification artifacts.
**Recommended action:** Run `/gsd-verify-work N` for phases 10–15, or accept as tech debt if manual testing confirms they work.

### GAP-02: ANNOT-06 Partial — Drag-Move Collapses Multi-Word Range

`moveAnnotation(id, wordIdx)` sets `wordStartIdx = wordEndIdx = wordIdx`. A span of N words becomes 1 word after drag-move.

**Fix:** `moveAnnotation(id, newStart)` should preserve `span = wordEndIdx - wordStartIdx` and set `wordEndIdx = newStart + span` (with overlap check).

### GAP-03: ANNOT-08 Partial — Edit Path Not Validated

The `+ Annotate` button is guarded by `selectionOverlaps` in TranscriptPanel. However, `AnnotationDialog` edit-submit calls `updateAnnotation()` without re-checking overlap, allowing overlapping annotations through the edit workflow.

**Fix:** Add `overlapsExisting(startIdx, endIdx, excludeId)` call in `AnnotationDialog.vue` submit handler for edit mode.

### GAP-04: SESSION-02 Partial — Double Listener Registration

`registerSaveOnClose()` called in both `App.vue:onMounted` and `AppShellView.vue:onMounted`. On each session open, a second `app:save-and-quit` IPC listener is added. On quit, save() and session:save-complete run twice.

**Fix:** Remove `sessionStore.registerSaveOnClose()` / `sessionStore.unregisterSaveOnClose()` from `AppShellView.vue`.
