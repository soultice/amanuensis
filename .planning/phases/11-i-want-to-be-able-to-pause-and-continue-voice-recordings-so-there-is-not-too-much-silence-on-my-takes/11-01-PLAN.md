<action>
Make the following changes to `src/renderer/src/stores/recording.ts`:

**1. Update the type alias** (line near top):

```typescript
// Before:
export type RecordingState = 'idle' | 'recording' | 'stopped'

// After:
export type RecordingState = 'idle' | 'recording' | 'paused' | 'stopped'
```

**2. Add two fields to the state object** (inside `state: () => ({...})`):

```typescript
    _pausedMs: 0,       // total milliseconds spent paused (accumulated across multiple pauses)
    _pauseStart: 0,     // timestamp (Date.now()) when the current pause began; 0 if not paused
```

**3. Update the `isRecording` getter** to return false when paused:

```typescript
// Before:
isRecording: (s): boolean => s.recordingState === 'recording',

// After:
isRecording: (s): boolean => s.recordingState === 'recording',
isPaused:    (s): boolean => s.recordingState === 'paused',
isActive:    (s): boolean => s.recordingState === 'recording' || s.recordingState === 'paused',
```

(`isActive` = true when either recording OR paused — used to show the Stop button)

**4. Add `pauseRecording()` action** (after `stopRecording()`):

```typescript
    pauseRecording(): void {
      if (this._recorder && this._recorder.state === 'recording') {
        this._recorder.pause()
        this._pauseStart = Date.now()
        this.recordingState = 'paused'
      }
    },

    resumeRecording(): void {
      if (this._recorder && this._recorder.state === 'paused') {
        if (this._pauseStart > 0) {
          this._pausedMs += Date.now() - this._pauseStart
          this._pauseStart = 0
        }
        this._recorder.resume()
        this.recordingState = 'recording'
      }
    },
```

**5. Update `stopRecording()`** to handle being called from the paused state, and to correctly compute duration:

```typescript
    stopRecording(): void {
      if (!this._recorder) return
      const state = this._recorder.state
      if (state === 'paused') {
        // Accumulate the current pause segment before stopping
        if (this._pauseStart > 0) {
          this._pausedMs += Date.now() - this._pauseStart
          this._pauseStart = 0
        }
        this._recorder.resume()  // must be 'recording' before .stop() is safe
        // Small delay to ensure the recorder transitions before stop
        setTimeout(() => this._recorder?.stop(), 0)
      } else if (state === 'recording') {
        this._recorder.stop()
      }
      // recordingState → 'stopped' is set in onstop handler
    },
```

**6. Update the `onstop` handler** inside `startRecording()` to use pause-aware duration:

```typescript
        recorder.onstop = () => {
          const blob = new Blob(this._chunks, { type: 'audio/webm' })
          this.audioBlob = blob
          this.audioBlobUrl = URL.createObjectURL(blob)
          // Subtract total paused time from elapsed time
          this.durationMs = Date.now() - this._startTime - this._pausedMs
          this.recordingState = 'stopped'
          this._stream?.getTracks().forEach(t => t.stop())
          this._stream = null
        }
```

**7. Reset pause state in `startRecording()`** (at the top where `_chunks = []` is reset):

```typescript
      this._chunks = []
      this._pausedMs = 0
      this._pauseStart = 0
```

**8. Reset pause state in `clearRecording()`** action:

```typescript
      this._pausedMs = 0
      this._pauseStart = 0
```
