# Plan 17-01: Extend CI to Linux and Windows

## Objective

The existing `.github/workflows/build.yml` only builds for macOS. Extend it to a matrix
build across all three major platforms — **Ubuntu (Linux)**, **Windows**, and **macOS** —
so that distributable binaries are verified and uploaded on every push to main.

Each job must:
1. Install Poetry (cross-platform approach)
2. Install Node dependencies
3. Install Python sidecar dependencies
4. Install PyInstaller into the Poetry environment
5. Build the Python sidecar binary (produces `dist-sidecar/amanuensis-sidecar/`)
6. Build the Electron renderer (Vite)
7. Package with electron-builder (produces `release/`)
8. Upload the platform-specific artifact

**Platform outputs:**
- Linux → AppImage (`release/*.AppImage`)
- Windows → NSIS installer (`release/*.exe`)
- macOS → DMG + ZIP (`release/*.dmg`, `release/*.zip`)

## Tasks

### Task 1: Rewrite build.yml as a matrix workflow

<read_first>

- sidecar/pyproject.toml (python version constraint: >=3.10,<3.15)
</read_first>

<action>
Replace `.github/workflows/build.yml` with the following content in full:

```yaml
name: Build

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]
  workflow_dispatch:

jobs:
  build:
    name: Build ${{ matrix.os }}
    runs-on: ${{ matrix.os }}
    timeout-minutes: 90

    strategy:
      fail-fast: false
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Set up Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '22'
          cache: 'npm'

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.12'

      # Install system deps needed by electron-builder on Linux
      - name: Install Linux system dependencies
        if: runner.os == 'Linux'
        run: |
          sudo apt-get update -y
          sudo apt-get install -y libasound2-dev libgtk-3-dev libnotify-dev \
            libgconf-2-4 libnss3 libxss1 libxtst6 xauth xvfb

      - name: Install Poetry (Linux/macOS)
        if: runner.os != 'Windows'
        run: |
          curl -sSL https://install.python-poetry.org | python3 -
          echo "$HOME/.local/bin" >> $GITHUB_PATH

      - name: Install Poetry (Windows)
        if: runner.os == 'Windows'
        run: |
          (Invoke-WebRequest -Uri https://install.python-poetry.org -UseBasicParsing).Content | python -
          $poetryBin = "$env:APPDATA\Python\Scripts"
          echo $poetryBin | Out-File -FilePath $env:GITHUB_PATH -Append
        shell: pwsh

      - name: Install Node dependencies
        run: npm ci

      - name: Install Python dependencies
        working-directory: sidecar
        run: poetry install --no-interaction

      - name: Install PyInstaller
        working-directory: sidecar
        run: poetry run pip install pyinstaller

      - name: Build sidecar (PyInstaller)
        run: npm run build:sidecar

      - name: Build Electron renderer
        run: npm run build

      - name: Package with electron-builder (Linux)
        if: runner.os == 'Linux'
        run: npm run build:electron
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - name: Package with electron-builder (Windows)
        if: runner.os == 'Windows'
        run: npm run build:electron
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - name: Package with electron-builder (macOS)
        if: runner.os == 'macOS'
        run: npm run build:electron
        env:
          CSC_IDENTITY_AUTO_DISCOVERY: false
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - name: Upload Linux artifact (AppImage)
        if: runner.os == 'Linux'
        uses: actions/upload-artifact@v4
        with:
          name: Amanuensis-Linux-AppImage
          path: release/*.AppImage
          if-no-files-found: error
          retention-days: 14

      - name: Upload Windows artifact (NSIS)
        if: runner.os == 'Windows'
        uses: actions/upload-artifact@v4
        with:
          name: Amanuensis-Windows-NSIS
          path: release/*.exe
          if-no-files-found: error
          retention-days: 14

      - name: Upload macOS artifact (DMG)
        if: runner.os == 'macOS'
        uses: actions/upload-artifact@v4
        with:
          name: Amanuensis-macOS-DMG
          path: release/*.dmg
          if-no-files-found: error
          retention-days: 14

      - name: Upload macOS artifact (ZIP)
        if: runner.os == 'macOS'
        uses: actions/upload-artifact@v4
        with:
          name: Amanuensis-macOS-ZIP
          path: release/*.zip
          if-no-files-found: warn
          retention-days: 14
```

Key decisions in this workflow:
- `fail-fast: false` — a failure on one OS does not cancel the other two
- `timeout-minutes: 90` — PyInstaller + electron-builder can take 30–60 min on slow runners
- `node-version: '22'` — matches the Volta pin in package.json
- `python-version: '3.12'` — satisfies `>=3.10,<3.15` from pyproject.toml
- Linux system deps (`libasound2-dev`, etc.) — required for native modules and audio support
- Poetry is installed differently on Windows (PowerShell script) vs Unix (curl)
- `CSC_IDENTITY_AUTO_DISCOVERY: false` on macOS — prevents code-signing failures in CI
