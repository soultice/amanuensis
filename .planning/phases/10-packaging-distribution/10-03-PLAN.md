<objective>
Harden the Electron main process for production: ensure the sidecar path is logged on startup, errors surface as user-visible dialogs (not silent crashes), and cleanup is guaranteed on all quit paths.

Purpose: In development, crashes are visible in the terminal. In the packaged `.dmg` app there is no terminal. Silent failures leave the user staring at a broken UI with no feedback. This plan makes the packaged app observable and resilient.

Output:
- `src/main/sidecar.ts` — production binary path logged at startup
- `src/main/index.ts` — error dialog on sidecar failure; `before-quit` handler calls `killSidecar()`
</objective>

### Task 2 — Add error dialog and robust quit handler to `index.ts`

<read_first>
- `src/main/index.ts` — the full current file; note how `startSidecar()` is called and how `app.on('before-quit', ...)` and `app.on('window-all-closed', ...)` are handled
</read_first>

<action>
In `src/main/index.ts`, make two changes:

**Change 1: Wrap `startSidecar()` call with an error dialog**

Find the call to `startSidecar()` in the `app.whenReady()` handler. It currently looks something like:
```typescript
await startSidecar()
```
or may be inside a try/catch already.

Ensure the sidecar startup failure shows a user-visible error dialog and quits cleanly. Replace the sidecar startup call with:

```typescript
try {
  await startSidecar()
} catch (err) {
  const message = err instanceof Error ? err.message : String(err)
  console.error('[main] Sidecar failed to start:', message)
  dialog.showErrorBox(
    'Amanuensis — Startup Error',
    `The transcription engine failed to start:\n\n${message}\n\nPlease reinstall the application.`
  )
  app.quit()
  return
}
```

Confirm `dialog` is already imported at the top of the file (it should be — check the existing import line). If not, add it to the electron import.

**Change 2: Guarantee `killSidecar()` on all quit paths**

Add (or verify it exists) a `before-quit` handler that kills the sidecar. This fires on Cmd+Q, window close on non-macOS, and programmatic `app.quit()`:

```typescript
app.on('before-quit', () => {
  killSidecar()
})
```

This must be registered ONCE in the main module scope (not inside `whenReady`). Check if it already exists; if so, verify `killSidecar()` is called inside it.

Also verify that `killSidecar` is imported from `./sidecar` — add to the import if missing.
</action>
