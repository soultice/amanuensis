Fix the electron-builder config gaps that will cause build failures or incorrect packaging, and ensure app icon files exist.

Purpose: Before any build can succeed, the icon and signing config must be correct. Without entitlements on the main process, a signed macOS app cannot use microphone or JIT. Without an icon, electron-builder uses a generic Electron icon.

Output:
- `package.json` build config updated with icon, mac targets, and entitlements
- `build/icon.png` — 1024×1024 placeholder PNG (or real icon if provided)
- `build/icon.icns` — converted from icon.png (macOS format)
- `build/icon.ico` — converted from icon.png (Windows format)
- `build/entitlements.mac.plist` — verified complete
</objective>

<action>
Verify the file contains exactly these entitlements. If any are missing, add them. The file must contain:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
  <dict>
    <key>com.apple.security.cs.allow-jit</key>
    <true/>
    <key>com.apple.security.device.microphone</key>
    <true/>
    <key>com.apple.security.cs.allow-unsigned-executable-memory</key>
    <true/>
  </dict>
</plist>
```

The `cs.allow-unsigned-executable-memory` entitlement is required by PyInstaller-built binaries on Apple Silicon — the frozen Python runtime executes memory that is not signed.

### Task 3 — Create app icon files

<read_first>
- `build/` directory listing — check what icon files already exist
</read_first>

<action>
Check if `build/icon.png` exists.

**If `build/icon.png` does NOT exist:** Generate a minimal 1024×1024 placeholder PNG using Python (guaranteed to be available in development):

```python
# Run this script: python3 scripts/make-icon.py
import struct, zlib, os

def make_png(width, height, color=(38, 139, 210)):
    """Generate a minimal solid-color PNG."""
    def chunk(name, data):
        c = zlib.crc32(name + data) & 0xffffffff
        return struct.pack('>I', len(data)) + name + data + struct.pack('>I', c)

    ihdr = struct.pack('>IIBBBBB', width, height, 8, 2, 0, 0, 0)
    raw = b''
    for _ in range(height):
        raw += b'\x00' + bytes(color) * width
    idat = zlib.compress(raw)

    return (b'\x89PNG\r\n\x1a\n' + chunk(b'IHDR', ihdr) +
            chunk(b'IDAT', idat) + chunk(b'IEND', b''))

os.makedirs('build', exist_ok=True)
with open('build/icon.png', 'wb') as f:
    f.write(make_png(1024, 1024, color=(38, 139, 210)))  # Solarized blue
print('Created build/icon.png (1024x1024 placeholder)')
```

Save as `scripts/make-icon.py` and run it: `python3 scripts/make-icon.py`

**Then generate platform-specific icon formats:**

For macOS `.icns` (requires macOS with iconutil):
```bash
mkdir -p build/icon.iconset
# Resize to required sizes using sips (built-in macOS tool)
for size in 16 32 64 128 256 512; do
  sips -z $size $size build/icon.png --out "build/icon.iconset/icon_${size}x${size}.png" 2>/dev/null
  double=$((size * 2))
  sips -z $double $double build/icon.png --out "build/icon.iconset/icon_${size}x${size}@2x.png" 2>/dev/null
done
iconutil -c icns build/icon.iconset -o build/icon.icns
rm -rf build/icon.iconset
```

For Windows `.ico`: electron-builder auto-converts on Windows. For macOS builds targeting Windows, the `.ico` is not needed. Create an empty placeholder if needed:
```bash
# electron-builder will use icon.png for Linux and can convert for Windows
# Only needed if building Windows installer on macOS
cp build/icon.png build/icon.ico 2>/dev/null || true
```

**If `build/icon.png` already exists:** Skip PNG generation. Still run the `iconutil` steps to generate `.icns` if it doesn't exist.
</action>
