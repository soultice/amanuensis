## Wave 4

### Task 1 — Run `npm run build:all` and fix any failures

<read_first>
- `package.json` — `build:sidecar`, `build`, `build:electron` scripts
- `sidecar/amanuensis-sidecar.spec` — final spec after plan 10-02
- `dist-sidecar/` — should exist from plan 10-02 smoke test
</read_first>

<action>
Run the full build pipeline from the project root:

```bash
npm run build:all
```

This runs three commands in sequence:
1. `npm run build:sidecar` — PyInstaller (may be skipped if `dist-sidecar/` is fresh from 10-02)
2. `npm run build` — electron-vite compiles the renderer + main TypeScript
3. `npm run build:electron` — electron-builder packages everything into `release/`

**Expected output:**
- `release/Amanuensis-<version>-arm64.dmg` (macOS dmg)
- `release/Amanuensis-<version>-arm64-mac.zip` (macOS zip, per D-05 in CONTEXT)
- Build exits 0

**Common failures and fixes:**

| Failure | Cause | Fix |
|---------|-------|-----|
| `extraResources: source not found` | `dist-sidecar/amanuensis-sidecar/` missing | Run plan 10-02 Task 2 first |
| `icon file not found` | `build/icon.png` missing | Run plan 10-01 Task 3 first |
| `entitlements file not found` | Wrong path in package.json | Verify `build/entitlements.mac.plist` path |
| `vite build` TypeScript error | Type error introduced in 10-03 | Fix TS error, re-run |
| `electron-builder: app-builder exited with code 1` | Usually icon format issue | Re-generate `build/icon.icns` with valid sizes |

Log all output to a file for debugging: `npm run build:all 2>&1 | tee /tmp/build-all.log`
</action>

<acceptance_criteria>
- `npm run build:all` exits 0
- `ls release/*.dmg` exits 0 (at least one .dmg file exists)
- `ls release/*.zip` exits 0 (at least one .zip file exists)
- `du -sh release/*.dmg` shows size > 50MB (confirms sidecar was bundled, not just Electron shell)
</acceptance_criteria>

### Task 2 — Smoke test the packaged `.app`

**Type:** checkpoint:user  
*(Requires human to open the .app and verify it works)*

<read_first>
- `release/` directory — find the produced `.dmg`
</read_first>

<action>
**Human steps (cannot be automated):**

1. Mount the `.dmg`: double-click `release/Amanuensis-*.dmg` in Finder
2. Drag the app to `/Applications` (or run directly from the DMG)
3. Launch `Amanuensis.app`
4. Observe:
   - App window opens (not a blank screen, not a crash)
   - No "application quit unexpectedly" dialog from macOS
5. Open Activity Monitor — find `amanuensis-sidecar` process running as a child of Amanuensis
6. In the app, open DevTools (View → Toggle Developer Tools if available in the build, or skip if production build disables it)
7. In DevTools console, run: `window.api.getSidecarPort()` — should return a port number (not null)
8. In Terminal: `curl http://localhost:<PORT>/health` with the port from step 7 — should return `{"status":"ok"}` or similar

**Pass criteria:**
- App window opens ✓
- No crash dialog ✓
- `amanuensis-sidecar` process visible in Activity Monitor ✓
- `/health` returns 200 ✓

**If sidecar fails to start:** The error dialog added in plan 10-03 should appear. Read the error message and fix the issue (likely a missing hidden import or incorrect resource path).

**After verifying:** Quit the app cleanly (Cmd+Q). Confirm `amanuensis-sidecar` process disappears from Activity Monitor within 5 seconds.
</action>

<acceptance_criteria>
- Human confirms: app window opens without crash
- Human confirms: `curl http://localhost:<PORT>/health` returns 200
- Human confirms: `amanuensis-sidecar` process exits within 5s of Cmd+Q
</acceptance_criteria>

### Task 3 — Create GitHub Actions workflow

<read_first>
- `.github/workflows/` directory — check if any workflow files already exist
- `package.json` — `build:all` script, app version, node engine requirement
</read_first>

<action>
Create `.github/workflows/build.yml`:

```yaml
name: Build macOS

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]
  workflow_dispatch:  # Allow manual trigger

jobs:
  build-macos:
    name: Build macOS (ARM64)
    runs-on: macos-latest  # Apple Silicon runner (macos-latest is ARM64 on GitHub Actions)
    timeout-minutes: 60

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Set up Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install Poetry
        run: |
          curl -sSL https://install.python-poetry.org | python3 -
          echo "$HOME/.local/bin" >> $GITHUB_PATH

      - name: Install Node dependencies
        run: npm ci

      - name: Install Python dependencies
        working-directory: sidecar
        run: poetry install --no-interaction

      - name: Build sidecar (PyInstaller)
        run: npm run build:sidecar

      - name: Build Electron app
        run: npm run build

      - name: Package with electron-builder
        run: npm run build:electron
        env:
          # Skip code signing for CI (no cert available)
          CSC_IDENTITY_AUTO_DISCOVERY: false
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - name: Upload DMG artifact
        uses: actions/upload-artifact@v4
        with:
          name: Amanuensis-macOS-DMG
          path: release/*.dmg
          if-no-files-found: error
          retention-days: 14

      - name: Upload ZIP artifact
        uses: actions/upload-artifact@v4
        with:
          name: Amanuensis-macOS-ZIP
          path: release/*.zip
          if-no-files-found: warn
          retention-days: 14
```

Also create `.github/workflows/` directory if it doesn't exist: `mkdir -p .github/workflows`
</action>
