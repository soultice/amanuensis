import importlib.util as _ilu
def importlib_path(pkg):

### Task 2 — Build the sidecar binary

<read_first>
- `sidecar/amanuensis-sidecar.spec` — updated spec (after Task 1)
- `package.json` scripts section — `build:sidecar` command
</read_first>

<action>
Run the sidecar build from the project root:

```bash
npm run build:sidecar
```

This executes: `cd sidecar && poetry run pyinstaller amanuensis-sidecar.spec --distpath ../dist-sidecar --workpath ../build-sidecar --clean`

**Expected output:**
- PyInstaller collects all modules, prints `Building COLLECT` step
- Final line: `Building COLLECT COLLECT-00.toc completed successfully.`
- `dist-sidecar/amanuensis-sidecar/` directory created

**If build fails with import errors:** Read the error message carefully. Missing modules will show as `ModuleNotFoundError` or `ImportError` during analysis. Add the missing module to `hiddenimports` and rebuild.

**Common ARM64 failures and fixes:**
- `Failed to execute script amanuensis-sidecar` → runtime hidden import missing, check stderr
- `No module named 'ctranslate2._ext'` → add `'ctranslate2._ext'` to hiddenimports
- `ImportError: libopenblas` → add `binaries=[(str(importlib_path('numpy')), 'numpy')]` to Analysis
</action>

### Task 3 — Smoke test the binary

<read_first>
- `src/main/sidecar.ts` — the `startSidecar()` function, to understand expected CLI args
</read_first>

<action>
Run the binary directly to confirm it starts and serves:

```bash
# Create a temp userData dir for the test
mkdir -p /tmp/amanuensis-smoke-test

# Start the sidecar on a fixed port in the background
./dist-sidecar/amanuensis-sidecar/amanuensis-sidecar --port 18999 --user-data /tmp/amanuensis-smoke-test &
SIDECAR_PID=$!

# Wait up to 15 seconds for it to be ready
MAX_WAIT=15
COUNT=0
until curl -sf http://localhost:18999/health > /dev/null 2>&1 || [ $COUNT -ge $MAX_WAIT ]; do
  sleep 1
  COUNT=$((COUNT+1))
done

# Check health endpoint
HEALTH=$(curl -sf http://localhost:18999/health 2>/dev/null)
echo "Health response: $HEALTH"

# Kill the sidecar
kill $SIDECAR_PID 2>/dev/null || true

# Verify we got a response
if [ -z "$HEALTH" ]; then
  echo "ERROR: Sidecar did not respond within ${MAX_WAIT}s"
  exit 1
fi
echo "SMOKE TEST PASSED"
```

If the sidecar crashes on startup, capture stderr:
```bash
./dist-sidecar/amanuensis-sidecar/amanuensis-sidecar --port 18999 --user-data /tmp/amanuensis-smoke-test 2>&1 | head -50
```
Read the error and add missing imports per Task 2 guidance, then rebuild.
</action>

<acceptance_criteria>
- `curl -sf http://localhost:18999/health` returns a non-empty JSON response (after binary is started)
- Health response contains `"status"` field (e.g., `{"status":"ok"}` or similar)
- Binary exits cleanly when sent SIGTERM: `kill -TERM $PID` returns exit code 0 or 143
- No `ImportError` or `ModuleNotFoundError` in sidecar stderr during startup
</acceptance_criteria>
