### B. Script changes

In `<script setup lang="ts">`, after the existing `const containerRef = ref<HTMLElement | null>(null)` line, add:

```typescript
const panelRef = ref<HTMLElement | null>(null)
let resizeObserver: ResizeObserver | null = null
```

**Modify the existing `watch(waveSurfer, (ws) => { ... })` block** to:
1. Add `ws.setOptions({ interact: false })` as the FIRST statement inside the callback
2. After the existing event wiring and `ws.load(...)` call, append the ResizeObserver setup:

```typescript
  // Set up ResizeObserver to keep wave div width and WaveSurfer height in sync
  // with the panel dimensions. Must run after ws is available.
  if (panelRef.value) {
    resizeObserver?.disconnect()
    resizeObserver = new ResizeObserver(([entry]) => {
      const { width, height } = entry.contentRect
      // After 90° rotation: wave div CSS width = panelHeight (so it fills height visually)
      if (containerRef.value) {
        containerRef.value.style.width = `${Math.floor(height)}px`
      }
      // WaveSurfer height option = panelWidth (fills the across-waveform visual width)
      ws.setOptions({ height: Math.floor(width) })
    })
    resizeObserver.observe(panelRef.value)
  }
```

**Add the custom seek handler function** anywhere in the script setup (e.g., after the
`watch(waveColors, ...)` block):

```typescript
function handlePanelClick(e: MouseEvent): void {
  if (!waveSurfer.value || !panelRef.value) return
  const rect = panelRef.value.getBoundingClientRect()
  // After 90° rotation, vertical position maps to audio time position
  const relativeTime = (e.clientY - rect.top) / rect.height
  waveSurfer.value.seekToProgress(Math.max(0, Math.min(1, relativeTime)))
}
```

**Modify `onUnmounted`** to disconnect the ResizeObserver before destroying WaveSurfer:

```typescript
onUnmounted(() => {
  resizeObserver?.disconnect()
  waveSurfer.value?.destroy()
})
```

**Do NOT change:** `useWaveSurfer` call, `regionsPlugin`, `waveColors`, `watch(recordingStore.audioBlobUrl)`,
`watch(playbackStore.selectionMin/selectionMax)`, `watch(waveColors)`, imports.

The `interact: false` set in the `watch(waveSurfer, ...)` block overrides the `interact: true`
in the `useWaveSurfer` options — this is intentional and correct.
