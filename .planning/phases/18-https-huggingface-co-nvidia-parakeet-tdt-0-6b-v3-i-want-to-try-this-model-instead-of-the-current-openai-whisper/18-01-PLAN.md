# Plan 18-01: Replace model-management stack with Parakeet ONNX

## Objective

Switch the sidecar model-management layer from faster-whisper/CTranslate2 assumptions to
Parakeet ONNX assumptions while preserving existing explicit download + progress UX.
This plan intentionally does not yet change transcription output logic.
