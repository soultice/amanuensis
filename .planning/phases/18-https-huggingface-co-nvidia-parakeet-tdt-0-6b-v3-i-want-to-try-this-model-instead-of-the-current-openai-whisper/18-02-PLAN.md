# Plan 18-02: Implement Parakeet transcription path and preserve UI contract

## Objective

Replace faster-whisper inference with Parakeet ONNX in the transcription service, preserve
word-level timeline behavior for annotation/navigation, and apply the product decision to
hide language when unavailable.

## Tasks

### Task 1: Rebuild transcription service for Parakeet + ffmpeg conversion

<read_first>
- sidecar/app/services/transcription.py
- sidecar/app/services/model_manager.py
- sidecar/app/routes/transcribe.py
- .planning/phases/18-https-huggingface-co-nvidia-parakeet-tdt-0-6b-v3-i-want-to-try-this-model-instead-of-the-current-openai-whisper/18-CONTEXT.md
- .planning/phases/18-https-huggingface-co-nvidia-parakeet-tdt-0-6b-v3-i-want-to-try-this-model-instead-of-the-current-openai-whisper/18-RESEARCH.md
</read_first>

<action>
Rewrite `sidecar/app/services/transcription.py` to:
- remove faster-whisper imports and model initialization
- load Parakeet model through `onnx_asr` from the model directory resolved by model_manager
- convert uploaded `.webm` files to 16kHz mono WAV using ffmpeg subprocess before inference
- run Parakeet recognition with timestamps enabled
- map token timestamps to word objects with required fields:
  `id`, `word`, `start`, `end`, `probability`, `segmentId`
- return response dict with keys exactly: `words`, `segments`, `language`, `duration`
- when backend language is unavailable, set `language` to empty string (`""`) so UI can hide it.

Keep thread-safe singleton model loading and current rounding conventions where practical.
</action>

<acceptance_criteria>
- `sidecar/app/services/transcription.py` contains `import onnx_asr`
- `sidecar/app/services/transcription.py` contains ffmpeg invocation (grep `ffmpeg` >= 1)
- `sidecar/app/services/transcription.py` does not contain `faster_whisper`
- `sidecar/app/services/transcription.py` returns dict keys `words`, `segments`, `language`, `duration`
- `cd sidecar && poetry run python -m py_compile app/services/transcription.py` exits 0
</acceptance_criteria>
