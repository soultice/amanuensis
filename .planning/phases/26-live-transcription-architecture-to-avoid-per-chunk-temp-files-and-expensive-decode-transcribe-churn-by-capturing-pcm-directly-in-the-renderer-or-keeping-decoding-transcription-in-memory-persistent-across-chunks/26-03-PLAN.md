<objective>
Move the renderer live-transcription client to PCM streaming with fail-fast startup.

Purpose: make renderer PCM capture the default live path on all supported platforms, with no hidden HTTP blob fallback and no polling-based transcript updates.
Output: an AudioWorklet PCM source, a live-stream websocket client, and renderer stores wired to the new prepare/stream/output protocol.
</objective>
