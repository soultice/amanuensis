Purpose: The renderer needs a way to persist a name change through the IPC bridge. The main process owns the index.json — it's the only place the name can be reliably written.

Output:
- `src/main/index.ts`: `session:rename` handler + default name change
- `src/preload/index.ts`: `renameSession(id, name)` exposed on `window.api`
</objective>

### Task 2 — Add `session:rename` IPC handler to main process

<read_first>
- `src/main/index.ts` — `ipcMain.handle('session:delete', ...)` block, and `readSessionIndex`/`writeSessionIndex` helpers (to confirm their signatures)
</read_first>

<action>
Add the following handler immediately after the `ipcMain.handle('session:delete', ...)` block:

```typescript
ipcMain.handle('session:rename', async (_event, id: string, name: string) => {
  const trimmed = name.trim()
  if (!trimmed) return  // ignore empty rename attempts
  const index = await readSessionIndex()
  const entry = index.find(s => s.id === id)
  if (!entry) return
  entry.name = trimmed
  entry.updatedAt = new Date().toISOString()
  await writeSessionIndex(index)
})
```
</action>
