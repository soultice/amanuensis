## Wave 2

### Task 1 — Add `sessionName` to store state and wire it up

<read_first>
- `src/renderer/src/stores/session.ts` — full file: state block, `openSession()`, `closeSession()`, `newSession()` actions
</read_first>

<action>
**1. Add `sessionName` to the state object** (next to `currentSessionId`):

```typescript
    sessionName: '' as string,          // display name of the active session; '' when no session open
```

**2. In `openSession(id)`**, after setting `this.currentSessionId = id`, load the name from the index:

```typescript
      // Load session name from index
      try {
        const sessions = await window.api.listSessions()
        const meta = sessions.find(s => s.id === id)
        this.sessionName = meta?.name ?? 'Untitled session'
      } catch {
        this.sessionName = 'Untitled session'
      }
```

**3. Add `renameSession(name)` action** (after `closeSession`):

```typescript
    async renameSession(name: string): Promise<void> {
      if (!this.currentSessionId) return
      const trimmed = name.trim() || 'Untitled session'
      await window.api.renameSession(this.currentSessionId, trimmed)
      this.sessionName = trimmed
    },
```

**4. Reset `sessionName` in `closeSession()`** (after `this.currentSessionId = null`):

```typescript
      this.sessionName = ''
```

**5. Also reset `sessionName` in `newSession()`** — `newSession()` calls `closeSession()` then opens a fresh session. After `newSession` calls `this.openSession(id)` for the new session, `sessionName` will be set by `openSession`. But the new session name needs to be set to "Untitled session" — which `openSession` will do automatically via the index lookup. No additional change needed if `newSession` calls `openSession`.

Verify: trace that `newSession()` eventually calls `openSession(newId)` — if it sets `currentSessionId` directly without calling `openSession`, manually set `this.sessionName = 'Untitled session'` after the new session is created.
</action>
