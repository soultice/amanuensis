<action>
**1. Add a `copied` ref** to the script section (after existing refs):

```typescript
const copied = ref(false)

async function copyTranscriptText(): Promise<void> {
  if (!transcriptStore.hasTranscript) return
  const text = transcriptStore.words.map(w => w.word).join('').trim()
  await navigator.clipboard.writeText(text)
  copied.value = true
  setTimeout(() => { copied.value = false }, 1500)
}
```

Add `ref` to the Vue import if not already present:
```typescript
import { ref } from 'vue'
```

**2. Add the Copy button to the template**, inside `<div class="annotation-panel__header">`, immediately before the Export button:

```html
      <button
        class="export-btn copy-btn"
        :disabled="!transcriptStore.hasTranscript"
        :title="transcriptStore.hasTranscript ? 'Copy transcript text to clipboard' : 'Transcribe first to enable copy'"
        @click="copyTranscriptText"
      >
        {{ copied ? '✓ Copied' : '⎘ Copy' }}
      </button>
```

**3. Add a small CSS override** for the copy button (same style as export, just use existing `export-btn` class — no new CSS needed unless you want a distinct colour). If you want a visual distinction, add:
