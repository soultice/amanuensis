# Plan 07-01: Image Export Block Formatting

## Objective

Fix the `exportMarkdown()` function so image annotations are emitted as block-level
Markdown elements. Currently, image markers are concatenated inline with transcript
words. After this fix, the output for an annotated segment will look like:

```
Some transcript text up to here
![](assets/image.png)
rest of the transcript text here
```

instead of the current broken inline form:

```
Some transcript text up to here![](assets/image.png)rest of the transcript text here
```

## Why

Standard Markdown renderers treat `![...]()` as inline by default, but when embedded
mid-sentence without surrounding newlines it results in images running into text.
Block rendering requires the image to appear on its own line, preceded and followed
by a newline (blank line is optional, bare newline is sufficient for most renderers).

<action>
Replace the segment loop inside `exportMarkdown()`. Current code (lines ~141–145):

```ts
const lines: string[] = ['# Transcript', '']
for (const segment of segments) {
  const segWords = words.filter(w => w.segmentId === segment.id)
  const line = segWords.map(w => w.word + (wordMarker.get(w.id) ?? '')).join('').trim()
  if (line) lines.push(line)
}
```

Replace with:

```ts
const lines: string[] = ['# Transcript', '']
for (const segment of segments) {
  const segWords = words.filter(w => w.segmentId === segment.id)
  let buffer = ''
  for (const w of segWords) {
    const marker = wordMarker.get(w.id) ?? ''
    if (marker.startsWith('![')) {
      // image → flush text buffer as its own line, then image on its own line
      const flushed = (buffer + w.word).trim()
      if (flushed) lines.push(flushed)
      lines.push(marker)
      buffer = ''
    } else {
      buffer += w.word + marker
    }
  }
  const remaining = buffer.trim()
  if (remaining) lines.push(remaining)
}
```

The key invariant: `marker.startsWith('![')` identifies image annotations only.
Link markers start with `[`, footnote refs start with `[^` — both remain inline.
</action>
