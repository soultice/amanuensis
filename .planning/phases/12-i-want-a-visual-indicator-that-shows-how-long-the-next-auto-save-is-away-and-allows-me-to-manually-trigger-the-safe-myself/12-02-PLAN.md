<objective>
Add a clickable auto-save progress bar to the toolbar that shows how far through the 30s save interval we are, and saves immediately when clicked (without resetting the countdown).

Purpose: The user wants to see when the next auto-save is coming and be able to trigger it early. The progress bar doubles as the manual save button — minimal UI surface for both needs.

Output: `AutoSaveBar` inline component inside AppToolbar.vue that reads `sessionStore.lastSavedAt` and animates via `requestAnimationFrame`.
</objective>

```typescript
const sessionStore = useSessionStore()
```

**2. Add the progress bar reactive state and animation loop:**

Add these after the existing `const activeStream = ref<MediaStream | null>(null)` line:

```typescript
// Auto-save progress bar
const saveProgress = ref(0)  // 0.0 – 1.0
let rafId: number | null = null

function animateSaveBar(): void {
  const elapsed = Date.now() - sessionStore.lastSavedAt
  const period = sessionStore.autoSavePeriodMs
  saveProgress.value = Math.min(elapsed / period, 1)
  rafId = requestAnimationFrame(animateSaveBar)
}

onMounted(() => {
  animateSaveBar()
})

onUnmounted(() => {
  if (rafId !== null) cancelAnimationFrame(rafId)
})

async function manualSave(): Promise<void> {
  await sessionStore.save()
  // Do NOT reset saveProgress — the countdown continues from the same lastSavedAt
  // (Note: save() updates lastSavedAt internally, so progress WILL reset to 0 after save)
}

const saveBarTitle = computed<string>(() => {
  const remaining = Math.ceil((sessionStore.autoSavePeriodMs - (Date.now() - sessionStore.lastSavedAt)) / 1000)
  const secs = Math.max(remaining, 0)
  return `Next auto-save in ${secs}s — click to save now`
})
```

**Note:** `animateSaveBar` runs continuously. Since `save()` updates `lastSavedAt = Date.now()`, the progress naturally resets to 0 after both auto-save AND manual save — this is correct behavior. The requirement "doesn't reset the countdown" means the `setInterval` 30s timer is NOT restarted on manual save (which it won't be, since we only call `save()` not `startAutoSave()`).

Also add `onUnmounted` to imports:
```typescript
import { ref, onMounted, computed, onUnmounted } from 'vue'
```

**3. Add the progress bar element to the template:**

In the template, find the theme toggle button (the last button in `.toolbar__controls`). Insert the progress bar BEFORE the theme button, right after the error indicator `<span>`:

```html
      <!-- Auto-save progress bar (Phase 12) — visible when session is active -->
      <button
        v-if="sessionStore.currentSessionId"
        class="save-bar"
        :title="saveBarTitle"
        @click="manualSave"
        aria-label="Save now"
      >
        <span class="save-bar__fill" :style="{ width: (saveProgress * 100) + '%' }" />
      </button>
```
