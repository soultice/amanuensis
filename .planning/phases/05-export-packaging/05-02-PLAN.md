```markdown
## Packaging

Building distributable installers requires building the Python sidecar first with PyInstaller,
then building the Electron app with electron-builder.

### Prerequisites

In addition to the dev prerequisites, install PyInstaller in the sidecar environment:

```bash
cd sidecar
poetry add --dev pyinstaller
poetry install
```

### Build steps

**1. Build the Python sidecar binary (platform-specific):**

```bash
npm run build:sidecar
```

This produces `dist-sidecar/amanuensis-sidecar/` — a standalone binary with no Python required.

**2. Build and package the Electron app:**

```bash
npm run build:all    # builds sidecar + renderer + electron installer
```

Or step by step:
```bash
npm run build         # Vite build (renderer)
npm run build:electron  # electron-builder (produces release/)
```

### Output

| Platform | Output | Location |
|---|---|---|
| macOS | `.dmg` | `release/` |
| Windows | `.exe` (NSIS) | `release/` |
| Linux | `.AppImage` | `release/` |

### Notes

- Whisper model weights (~3 GB) are **not bundled**. They are downloaded on first launch.
- Build each platform's binary on the target platform (macOS binary on macOS, etc.).
- For CI, use GitHub Actions with separate jobs per platform.
```
